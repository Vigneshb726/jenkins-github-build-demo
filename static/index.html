Jenkins Setup Guide

How to run this experiment on a real Jenkins server

  1. Push the project to GitHub

    Create a public repository and push this project (Hello.java is in sample-app/):

    git init
git add .
git commit -m "Add Jenkins x GitHub build demo"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/jenkins-github-build-demo.git
git push -u origin main

  2. Install and start Jenkins

    Install Jenkins with the Windows installer (or run java -jar jenkins.war), open http://localhost:8080, unlock it, and install the suggested plugins (these include the Git plugin). Jenkins needs Git and a JDK on its machine.

  3. Create a Freestyle job

    New Item → name Hello-Java-Build → Freestyle project → OK.

  4. Connect the GitHub repository

    Source Code Management → Git → Repository URL https://github.com/YOUR-USERNAME/jenkins-github-build-demo.git, Branch Specifier */main. A public repository needs no credentials.

  5. Add the build commands

    Build Steps → Add build step → Execute Windows batch command:

    cd sample-app
javac Hello.java
java Hello

    On Linux, use Execute shell with the same two commands. See jenkins/ for complete versions.

  6. Trigger the build

    Click Save → Build Now. Open the build → Console Output. It should show Hello, Jenkins! and Finished: SUCCESS.

  7. (Optional) Connect this dashboard

    In Jenkins: your name → Security → API Token → Add new token. Copy .env.example to .env, fill in the values, and restart python app.py. The Run Real Jenkins Build button then appears.
